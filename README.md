# One-Line Roast: The Gadget You Use Every Day — u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610

One original line roasting a gadget used every day: the microwave.

## Entry

> My microwave beeps five times when my food is ready, then beeps again every minute, as if I'll forget the meal I was standing right in front of.

## How it runs

`main.py` (Python 3, standard library only) writes the single roast to
`/output/entry.txt`. The program is deterministic: every run writes the
exact same bytes. The roast is 144 characters, inside the 200-character
limit in the kit.

## Why this roast

It names one specific gadget and one concrete behaviour everyone with
a microwave recognises: five beeps to say the food is ready, then a
beep every minute after, as if the cook had wandered off — when in
fact they were standing right in front of it the whole time. The sting
is the last clause, and no word is wasted getting there. The roast is
original, written for this bounty, not copied from any other entry.
